# Python Activity-Based Learning

This repository contains the complete college semester project for **Python Programming: Activity-Based Learning**. It consists of 10 comprehensive case studies designed using fundamental Python programming constructs — strictly utilizing variables, data types, operators, conditional statements, loops, strings, lists, nested lists, tuples, and tuple unpacking, with no external libraries, imports, or user-defined functions.

## How to Run

Ensure Python 3 is installed. From the repository root directory, run any case study program using:

```bash
python programs/case01_electricity_billing.py
```

Replace `case01_electricity_billing.py` with any program file name from `programs/` to run that specific case study.

## Documentation

1. **Individual Case Study Activity PDFs (`outputs/`)**: Separate PDF reports for each of the 10 case studies (`case01_electricity_billing.pdf` through `case10_product_catalogue_audit.pdf`), containing problem statements, objectives, assumptions, algorithms, flowcharts, pseudocode, source code, test cases, outputs, and conclusions.
2. **Complete Combined Project Report (`docs/Python Activity-Based Learning - 10 Selected Case Studies.pdf`)**: All 10 case studies compiled into a single 39-page project report.
3. **VS Code Execution Screenshots PDF (`docs/VS Code Python Execution Screenshots - 10 Case Studies.pdf`)**: Compiled PDF of Visual Studio Code editor and terminal execution screenshots for all 10 case studies.
4. **Individual High-Resolution VS Code Screenshots (`docs/vscode_screenshots/`)**: 10 separate PNG images showing each case study running in VS Code with its terminal output.
5. **Standalone Case Study Folders (`individual_projects/`)**: 10 self-contained project directories, each packaged with its own `README.md`, `.gitignore`, `.py` script, activity PDF, and VS Code screenshot.
